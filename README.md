# PowerBi-Dax-Mini-Project

📊 Project Overview
This repository contains my Power BI DAX Mini Project, where I applied advanced DAX concepts such as measures, calculated columns, and running totals to build interactive dashboards for sales and revenue analysis.

The project demonstrates:

Building dynamic measures using DAX.

Creating TopN product analysis with calculated columns.

Visualizing state-wise sales performance.

Tracking net revenue, profit, and cumulative growth over time.

🗂️ Datasets
Sales Dataset: Contains product, customer, employee, and state-level sales data.

Revenue Dataset: Includes transaction-level revenue and profit measures.

⚙️ Key Features
TopN Analysis: Revenue contribution by top products.

State Comparison: Sales breakdown across California, Florida, and Arizona.

Employee & Customer Insights: Performance tracking by individuals.

Time Intelligence: Running totals and cumulative revenue trends.
